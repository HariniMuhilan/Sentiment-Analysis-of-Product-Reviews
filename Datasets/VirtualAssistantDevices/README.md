# Virtual Assistant Devices review benchmark

This repository includes the source spreadsheet and a normalized CSV for a small, human-annotated, cross-retailer smart-device review benchmark.

## Files and preparation

- `raw/Virtual_Assistant_Devices_Dataset.xlsx` — unchanged file downloaded from Mendeley Data.
- `processed/virtual_assistant_reviews.csv` — deterministic normalization generated by [`research/prepare_external_benchmarks.py`](../../research/prepare_external_benchmarks.py). Blank product, manufacturer, and platform cells in the source workbook are filled from the preceding grouped row; aspect columns are combined without changing their wording. Workbook padding at review line endings is trimmed; review wording is retained.

The processed file has **2,370 reviews** from **10 device models**. The retailer counts in the file are Amazon 669, Best Buy 855, eBay 21, Target 424, and Walmart 401. Five device models have reviews from more than one named retailer. The labels in the downloaded file are 842 positive, 774 negative, and 754 neutral.

**Data quality note:** the Mendeley description and paper report 842 positive, 800 negative, and 728 neutral labels. The downloaded spreadsheet instead contains 842 positive, 774 negative, and 754 neutral labels. The total remains 2,370. Keep the downloaded labels unchanged and do not use this file as a gold evaluation benchmark until this discrepancy is resolved with the dataset authors.

The spreadsheet has no numeric ratings, review dates, or global product IDs. Device models are grouped by the repeated device name in the source; the study only supports cross-retailer comparison for the five names that have more than one source. Verify product identity and sample balance before making model-level claims. App VADER scores are exploratory and are not validated by the source authors' labels.

## Intended use and limits

This is a separate, small, cross-retailer benchmark for smart-device sentiment/aspect research. It is not merged with the 2.8-million-row Amazon Reviews 2023 corpus and does not establish broad marketplace-wide differences. Do not infer current prices or current review counts from it.

To add its English review text to the local searchable application database, run from the repository root:

```powershell
python research/prepare_external_benchmarks.py
cd backend
..\.venv\Scripts\python.exe run_ingest.py --platform generic --file ..\Datasets\VirtualAssistantDevices\processed\virtual_assistant_reviews.csv --dataset-name virtual-assistant-devices --dataset-version 1
```

The app applies its current VADER model during import; it does not use the dataset's human sentiment labels as app predictions. The workbook has no review dates or star ratings, so those values remain missing.
