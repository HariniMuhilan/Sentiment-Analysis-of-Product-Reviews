# BanglaEcomReviewCorpus

This repository includes the source spreadsheet and a normalized CSV for a human-labeled Bengali (Bangla) e-commerce sentiment corpus collected from multiple public shopping and commerce websites.

## Files and preparation

- `raw/BanglaEcomReviewCorpus.xlsx` — unchanged spreadsheet from Mendeley Data version 2.
- `processed/bangla_ecom_reviews.csv` — deterministic normalization generated by [`research/prepare_external_benchmarks.py`](../../research/prepare_external_benchmarks.py). It retains the original Bengali sentence, the provided English translation, and the source sentiment label; only workbook padding at line endings is trimmed.

The prepared file has **8,685** rows: 3,012 positive, 2,881 negative, and 2,792 neutral. All rows have Bengali text and a populated English-translation field.

The article describes reviews collected across Daraz, Bikroy.com, Pickaboo, Shajgoj, and other sources. **The released rows do not include a platform name, product identifier, or product name.** Use this as a separate multilingual sentiment benchmark only. It cannot support platform-specific comparisons, matched-product analysis, or attribution of a particular review to one retailer. The paper's translation procedure is not sufficiently documented to treat the English translations as an independent English-language benchmark; prefer the original Bangla text for Bengali model evaluation.

## Intended use and limits

Keep this corpus separate from the English Amazon dataset and Portuguese Brazilian datasets. Do not score the original Bangla text with the project's English-oriented VADER model and treat the result as valid sentiment analysis. Use a Bengali-capable model and report the corpus as external validation data, including the source-level limitations above.
